# Алиса + Gemini + Serper

Персональный навык на Vercel: компьютер пользователя может быть выключен.
Основан на ruslanpodzorovraw-collab/alice-gemini-serper-template; лицензия сохранена.

## Как работает

1. Обработчик сначала получает быстрый ответ Gemma 4 26B A4B через отдельный Cloudflare Worker с отключённым внутренним рассуждением. Поисковый контекст предоставляет Serper.
2. Готовый ответ сразу выдаётся пользователю; Vercel Workflow сохраняет текст и историю без повторной генерации. Команда «Дальше» не нужна.
3. Быстрая генерация ограничена 2,8 секунды от начала HTTP-запроса; остаток времени оставлен для надёжного сохранения результата и доставки Алисе.
4. Если быстрый запрос не успел или сервис недоступен, создаётся фоновая задача. Она может повторно вызвать быстрый сервис и при его сбое обратиться к прежней Gemini. Если результат готов до общего срока 3,4 секунды, он выдаётся сразу; иначе «Дальше» остаётся запасным способом получения ответа.
5. История сохраняется в Workflow: до восьми последних реплик. В session_state — только подписанный идентификатор задачи, привязанный к сессии.

Обычный API навыков Яндекса не предусматривает автоматическую реплику «Дальше» или произвольную отправку нового текста после завершённого ответа. Быстрый путь уменьшает необходимость этой команды, но не гарантирует отсутствие её при каждом запросе. При таймауте прямого запроса возможен повторный вызов модели в фоне; в успешном быстром пути генерация одна.
Отдельный VPS или включённый компьютер не требуются. Голосовой ответ ограничен 1024 символами; session_state — 950 байтами.

## Настройка

Vercel автоматически определяет Next.js из vercel.json. Нужны переменные Production и Preview:

- GEMINI_API_KEY: ключ Google AI Studio для резервной модели.
- FAST_LLM_URL: HTTPS-адрес /generate выделенного Cloudflare Worker (домен workers.dev).
- FAST_LLM_TOKEN: отдельный случайный секрет для этого обработчика; на стороне Worker хранится как ACCESS_TOKEN.
- SERPER_API_KEY: ключ Serper для вопросов с явными признаками актуальности/поиска.
- ALICE_ACCESS_TOKEN: отдельная случайная строка не короче 32 символов; это не ключ Gemini/Serper.
- GEMINI_MODEL: необязательно; по умолчанию gemini-3.5-flash-lite.
- ALICE_SKILL_ID: необязательное дополнительное ограничение на навык.
- WORKFLOW_NODE_HTTP=1: обязательный режим стандартного Node HTTP для совместимости с обновлённой undici.

В настройках проекта должен быть включён OIDC. SDK получает токен из контекста запроса; отсутствие VERCEL_OIDC_TOKEN в process.env само по себе не означает ошибку.

После изменения переменных нужно новое развёртывание.
Webhook Яндекс Диалогов: https://YOUR-DOMAIN/api?token=YOUR-ALICE-ACCESS-TOKEN .
Адрес содержит секрет: не публикуйте его. Нужна передача session_state между репликами (хранилище навыка).

GET /api возвращает проверку доступности без ключей. POST требует секрет.
DIAGNOSTICS_TOKEN временно открывает POST /api/diagnostics с Bearer-токеном для фиксированных проверочных запросов. В Production не включать.

## Ограничения и данные

Тексты вопросов, ответы и краткая история сохраняются в инфраструктуре Vercel Workflow на срок хранения платформы. Для быстрого ответа вопрос и контекст передаются Cloudflare Workers AI (Gemma 4); для резервного — Google Gemini. Поисковый запрос передаётся Serper. Сам выделенный Worker не сохраняет историю, а вывод журнала запросов отключён. Не отправляйте в навык секреты.

Исходник Worker — cloudflare/fast-answer.js. Он имеет только привязку AI и отдельный секрет ACCESS_TOKEN, принимает максимум 10 текстовых сообщений, вызывает фиксированную модель и не поддерживает произвольные URL, инструменты или передачу ключей Google/Serper. Workers AI имеет бесплатную дневную квоту 10 000 Neurons; действуют также ограничения тарифов и общая нагрузка аккаунта. Новые платные подписки этой настройкой не включаются.
Поиск определяется простыми признаками, например «найди», «сегодня», «сейчас»; он не гарантирует автоматическое распознавание каждого вопроса о свежих фактах. При ошибке поиска модель не отвечает из устаревшей памяти.
Gemini Free Tier и Serper имеют квоты. Workflow также имеет лимиты Hobby; бесконечная бесплатная работа не обещается. Платные планы автоматически не включаются.
Дубли транспортной доставки одного нового вопроса могут создать отдельные задачи; обычные проверки «Дальше» не дублируют вызовы API.
